## Recovery fix

The complete regression run exposed a problem with Node's environment-proxy global agents: a pinned webhook or user RPC could connect through the global agent instead of using its validated IP. Pinned transports now use a separate connection, retaining the requested Host, TLS SNI, certificate validation, response caps and deadlines. Regression coverage checks that the global connection agent is never used for these pinned requests.
