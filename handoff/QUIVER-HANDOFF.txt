======================================================================
1. WHAT QUIVER IS
======================================================================
Quiver is an AI strategy builder for Robinhood Chain, inspired by Weft.fi's node-graph builder.
You type a trading idea in plain English; it is compiled into a graph of signals -> triggers ->
actions -> exits that you can paper trade (live SSE), backtest, share, fork and (later) run live
via session keys. It also covers Solana, Hyperliquid and Polymarket venues; tokenized stocks
(Robinhood Chain Stock Tokens: NVDA, AAPL, TSLA, SPY ...) are a venue.
Tagline: "Every strategy is an arrow."  Ticker: $QUIVR (no token launched, see section 9).
Chains: Robinhood Chain testnet 46630 (default), mainnet 4663 (read-only price feeds only; all
mainnet execution is gated).
Current state: mock / paper mode with mainnet-readonly Chainlink prices, public preview on a VPS.
Nothing runs with real funds. No private keys are configured on the server - all signing is meant
to happen in the user's browser wallet.

Team roles seen in the docs: Sage = backend, Wren = web, Ellis = motion/animation, Robin = QA gate +
VPS operator, Honey/Remy = product/copy approvals, Gofi = owner (keys, accounts, decisions).

3. RUN LOCALLY
======================================================================
Backend (quiver/backend):
  npm ci
  cp .env.example .env      (all values empty = MOCK mode; never commit real values)
  npm run dev               (tsx watch src/main.ts)   or  npm start
  Default port 8787, host 127.0.0.1 (HOST, PORT). For the web dev login set DEV_LOGIN_ENABLED=true
  and CORS_ORIGINS=<exact web origin, e.g. http://localhost:4317> (no wildcards).
  Optional: PRICE_SOURCE=mainnet-readonly (read-only Chainlink eth_call on 4663).
  Dev persistence: .data/dev-store.json (QUIVR_DEV_PERSIST=1; gitignored; NOT included in zip).
  Tests:  npm test (vitest run; last gate: 81 files / 548 tests green), npm run test:unit,
          npm run test:integration, npm run typecheck, npm run lint (after npm run lint:install),
          npm run fixtures:check, scripts/checks.sh (all checks; fails on fixture drift / tree change).
  Solidity: cd foundry && forge build && forge test   (anvil tests use free ports).
Web (quiver/web):
  npm ci
  cp .env.example .env.local
     NEXT_PUBLIC_API_MODE=mock|live   NEXT_PUBLIC_API_BASE=http://localhost:<backend port>/v1
     NEXT_PUBLIC_DEV_LOGIN=1          QUIVER_API_INTERNAL (server-side SSR/OG fetch base, default
     http://127.0.0.1:8987/v1)        PUBLIC_BASE_URL (metadataBase; set for build AND start)
     NEXT_PUBLIC_PRIVY_APP_ID (public, optional)   INTERNAL_PROXY_TOKEN (server-only, = backend value)
  npm run dev | npm run build && npm start | npm run lint | npm run typecheck
  Mock mode works with no backend at all. Contracts: re-sync with scripts/sync-contracts.sh after
  backend contract changes.
